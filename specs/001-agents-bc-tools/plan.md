# Implementation Plan: Agent Selection with Business Central Tools

**Branch**: `001-agents-bc-tools` | **Date**: 2026-06-03 | **Spec**: [spec.md](spec.md)

---

## Summary

Transform the home page bot-selection UI into a purpose-oriented agent-selection experience. Introduce an `agent_type` field on the existing `bots` table to activate toolsets per agent. Implement the first toolset — `promo_discount` — with two Business Central SQL Server tools (`get_bc_tables`, `select_bc_table`). Wire an agentic loop into the chat service so the LLM can call these tools, receive results, and stream a final grounded response.

### Phase B — BC Tools (new backend package)

**B1. `backend/src/tools/bc_connection.py`**

```python
async def open_bc_connection(dsn: str):
    return await aioodbc.connect(dsn=dsn, autocommit=True)
```

**B2. `backend/src/tools/bc_tools.py`**

`get_bc_tables(conn_str: str) -> list[str]`
- Opens BC connection
- `SELECT TABLE_NAME FROM INFORMATION_SCHEMA.TABLES WHERE TABLE_TYPE='BASE TABLE' ORDER BY TABLE_NAME`
- Returns list of table names, closes connection

`select_bc_table(conn_str, table_name, columns=None, filters=None) -> str`
- Validates `table_name` matches `r'^[A-Za-z0-9_ $]+$'` — raises `ValueError` otherwise
- Validates each column name with same pattern
- Builds: `SELECT TOP 200 [col, ...] FROM [table] WHERE col op ? AND ...`
- All filter values are ODBC `?` parameters — never interpolated into SQL
- Allowed ops: `=`, `!=`, `>`, `>=`, `<`, `<=`, `LIKE`
- Converts rows to list of dicts, returns `json.dumps(rows)`

**B3. `backend/src/tools/registry.py`**

```python
from dataclasses import dataclass
from typing import Callable, Awaitable

@dataclass
class AgentToolset:
    definitions: list[dict]
    executor: Callable[[str, dict], Awaitable[str]]

# Anthropic tool definition schemas (GET_BC_TABLES_DEF, SELECT_BC_TABLE_DEF) defined here.
# bc_tool_executor: dispatches tool_name to get_bc_tables or select_bc_table,
#   wraps exceptions into {"error": "..."} JSON.

AGENT_TOOLS: dict[str, AgentToolset] = {
    "promo_discount": AgentToolset(
        definitions=[GET_BC_TABLES_DEF, SELECT_BC_TABLE_DEF],
        executor=bc_tool_executor,
    )
}
```

### Phase C — Agentic Loop (backend)

**C1. `providers/base.py`**

Extend protocol with `stream_with_tools` that yields `str` (token) or `dict` (event):

```python
async def stream_with_tools(
    self,
    messages: list[dict],
    config: LLMProviderConfig,
    toolset: "AgentToolset",
) -> AsyncIterator[str | dict]:
    ...
```

Event dict shapes:
- `{"event": "tool_call", "data": {"tool": "select_bc_table", "args": {...}}}`
- `{"event": "tool_result", "data": {"tool": "select_bc_table", "row_count": 15, "success": true}}`

**C2. `providers/anthropic_provider.py` — agentic loop**

```
MAX_TOOL_ROUNDS = 5
loop up to MAX_TOOL_ROUNDS:
  response = await client.messages.create(
      model, max_tokens, system, messages,
      tools=toolset.definitions, tool_choice={"type": "auto"}
  )
  tool_use_blocks = [b for b in response.content if b.type == "tool_use"]

  if tool_use_blocks:
    tool_results = []
    for block in tool_use_blocks:
      yield {"event": "tool_call", "data": {"tool": block.name, "args": block.input}}
      try:
        result_json = await toolset.executor(block.name, block.input)
        row_count = len(json.loads(result_json)) if result_json.startswith("[") else 0
        yield {"event": "tool_result", "data": {"tool": block.name, "row_count": row_count, "success": True}}
      except Exception as e:
        result_json = json.dumps({"error": str(e)})
        yield {"event": "tool_result", "data": {"tool": block.name, "row_count": 0, "success": False, "error": str(e)}}
      tool_results.append({"type": "tool_result", "tool_use_id": block.id, "content": result_json})
    messages.append({"role": "assistant", "content": response.content})
    messages.append({"role": "user", "content": tool_results})
    continue

  else:
    # Final answer: stream as text tokens
    text_blocks = [b for b in response.content if b.type == "text"]
    if text_blocks:
      # Already have text — stream it character by character or yield whole
      # Use streaming API for proper token-by-token output
      async with client.messages.stream(
          model=config.model, max_tokens=config.max_tokens,
          system=config.system_prompt, messages=messages,
          temperature=config.temperature,
      ) as stream:
        async for text in stream.text_stream:
          yield text
    break
```

**C3. `services/chat_service.py` — routing**

In `_stream_generator`, after loading the bot and building payload:

```python
from src.tools.registry import AGENT_TOOLS

toolset = AGENT_TOOLS.get(bot.agent_type) if bot.agent_type else None

if toolset and bot.provider == "anthropic":
    async for item in provider.stream_with_tools(payload, config, toolset):
        if isinstance(item, str):
            assembled.append(item)
            yield f"event: token\ndata: {json.dumps({'token': item})}\n\n"
        else:
            yield f"event: {item['event']}\ndata: {json.dumps(item['data'])}\n\n"
else:
    async for token in provider.stream(payload, config):
        assembled.append(token)
        yield f"event: token\ndata: {json.dumps({'token': token})}\n\n"
```

The remainder of `_stream_generator` (persist message, audit log, auto-title) is unchanged.

## Out of Scope (v1)

- Admin UI for agent management — direct DB inserts for now
- Tool calling for OpenAI or Gemini providers — Anthropic only
- Multiple BC connections — single `BC_DATABASE_URL` env var
- Streaming tool-input deltas — non-streaming rounds for tool calls
- Row-level security within BC — relies on read-only service account permissions
